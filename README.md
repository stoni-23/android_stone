# Stargame

Portrait Retro-Pixel-Shooter (Reichszeitglocke V-3). Kotlin / Jetpack Compose.

## APK herunterladen

**[stargame-debug.apk](https://github.com/stoni-23/android_stone/releases/latest/download/stargame-debug.apk)**

Auch unter [Releases](https://github.com/stoni-23/android_stone/releases/latest).

## Spielen

Intro antippen. Die Glocke dreht um die eigene Achse.

- **Links schieben:** drehen + Schub
- **Rechts halten:** feuern
- Gegner: `BASIC`, `LANG`, `RUND`, `BIG`
- Drei Wellen, dann Sieg. Game Over: **Erneut spielen** oder **Hauptmenü**
